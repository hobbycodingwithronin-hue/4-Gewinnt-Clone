# 🔴 4 Gewinnt (Connect Four) mit Python & KI

Willkommen auf dem GitHub-Repository zu meinem YouTube-Video auf dem Kanal **Hobby Coding with Ronin**! 

In diesem Projekt bauen wir den Klassiker 4 Gewinnt in Python – komplett ohne den Code mühsam selbst zu schreiben. Ich zeige dir, wie man mit cleveren Ideen und KI (Gemini) in kürzester Zeit ein funktionierendes Spiel mit grafischer Benutzeroberfläche und einem cleveren KI-Gegner auf die Beine stellt.

Stelle sicher, dass Python auf deinem PC installiert ist. Lade dir die Python-Datei (vier_gewinnt.py) aus diesem Repository herunter und starte sie in deiner Entwicklungsumgebung (z.B. VS Code) mit folgendem Befehl: python 4_gewinnt_mit_ki.py
